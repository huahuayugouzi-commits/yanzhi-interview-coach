# 行为题诊断升级 V1.2

## 修改思路
保留 V1.1 的能力焦点、证据判断、原文依据、单缺口追问与二答验收结构；将判断标准按题目区分，避免把 STAR 当硬模板。

## 修改内容与原因
- 新增方案取舍、失败复盘、协作分歧三个入口，原自我介绍与项目介绍保持兼容。
- 删除“列出组织协调动作后只能问结果”的一刀切规则。取舍重点看选择依据；失败重点看责任、补救与后续变化；协作重点看分歧、对方诉求与个人推进方式。各项只是内部检查依据，每次只补一个缺口。
- 不按固定秒数和比例扣分，不要求数字、不因“我们”否定贡献、不要求执行任务包装为战略决策；已有充分证据即停止纠偏。
- 二次回答按原追问验收，补测试通过不等于补了方案选择依据；补齐理由后不追加业务结果。
- 提示词要求一次只给一个重说提示，减少把多个新任务塞进提示的情况。
- 真实试验发现格式修复只收到错误代码、没有上次输出与字段路径。现在仅在失败重试时附上上一响应与 AJV 校验路径，帮助修正层级；仍最多两次调用，不改变数据发送目的地或日志策略。

## 验证与限制
28/28 Node 接口安全及修复测试；16/16 桌面和 393×852 手机流程测试；TypeScript 与生产构建通过。页面测试成功诊断与 ASR 使用 mock，不替代真实模型测试或 iPhone 真机验收。
真实模型报告：docs/evaluation/behavior-upgrade.json，含 8 个跨题型首答与 2 个决策题二答。语义由 Codex 自审，不是用户研究或泛化准确率保证。
初轮存在字段嵌套错误及复合追问，修正重试上下文与单焦点例子后再验证；第二轮发现提示词附加了追问之外的任务，进一步收敛为一个提示后复测。最终结果见报告。
