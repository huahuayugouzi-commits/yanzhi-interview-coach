# 自由返回步骤导航验收记录

本轮修改：src/App.tsx、src/Recorder.tsx、src/styles.css、tests/e2e.spec.ts；另有实施计划与本记录。保留上轮本地JD/口语策略改动，本轮没有新增Prompt、API或依赖改动，没有推送或部署。

- stage只表示当前查看页，progress表示已到达的可进入范围；步骤按钮不能越过范围，繁忙/录音时禁用导航。当前高亮，已完成可悬停与点击。手机侧栏隐藏时提供上一步，原有开始训练/进入重说按钮可返回后续结果。
- 切换只更新查看状态，不清JD、简历、转写、诊断、补充、Guidance、Compare，不自动调用模型。已有Guidance/Compare重进不再清空或重生成。
- 编辑按钮先进入编辑视图，保留原结果；实际改值时确认。取消保留原值和结果。确认修改JD/简历/题目/首次回答后清理相关下游结果与补充/重说；修改补充仅清Guidance、Compare和重说；修改第二答仅清Compare。上下文修改重置准备进度，首次回答修改锁住第三步。
- 三段录音Blob与时长由App按首次/补充/重说分别保存，Recorder重挂载重新创建可播放URL；组件卸载释放URL，结束训练或账号更换清理内存录音。未引入持久化或上传录音的新行为。
