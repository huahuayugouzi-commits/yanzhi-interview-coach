# JD 导向与自然口语增量验收记录

范围：本地最小修改，保留 d9c3068 的表达优化框架、共享补充思路、按需追问、Guidance、Compare 及卡片样式。未修改模型配置、接口路径、响应 Schema、依赖或部署设置。

## 实际改动
- server/prompts.mjs：共享 JD/口语规则；从 JD 识别最多三项核心能力（可少于三项），按题选择；区分简历背景与本次实际回答；现有 capability_focus 记录 JD 核心和本题重点。口语训练避免模板、术语堆砌、重复和冗长，不贬低正常口语；不编造声音或自信判断。
- server/contracts.mjs：Guidance/Compare 输入各增加可选 capability_focus（非空字符串，最多200字符）；旧输入仍有效，无输出字段变更。
- src/App.tsx：把首次诊断 capability_focus 原样传到 Guidance/Compare，同一轮不另行生成标准；仅增加指定重说提示，不改变布局或样式。
- Compare：沿用原标准，按本题比较匹配、证据、重点与逻辑、文本口语自然度；长度、书面化、贴近框架本身不算进步。可区分表达改善与证据未增加，不新增评分。
- tests/jd-oral.test.mjs：9项新增契约、Mock传输、合成输入/规则检查；tests/e2e.spec.ts：在既有6类桌面/手机流程中检查参考传递和重说提示。

## 合成回归与人工复核重点
| 案例 | 工程断言 | 真实模型待判断 |
| --- | --- | --- |
| JD模糊 | 输入原样保留、规则存在 | 是否少于三项、不臆造标准 |
| 简历有、口头无 | 来源保留、规则存在 | 不把简历案例当已说证据 |
| 自然口语 | Guidance携带原文、规则存在 | 不改为术语或完整稿 |
| 扩写为书面空话 | Compare携带两答、规则存在 | 不因长度或书面化判进步 |
| 缩短且重点更清楚 | Compare携带两答、规则存在 | 认可组织改善但不虚构证据增加 |
| 只有ASR文本 | 文字输入、规则存在 | 不判断语速、停顿、语调、自信 |

上述规则检查和Mock输出不证明模型会正确执行。真实模型的核心能力提炼、标准稳定性、口语自然度及Compare语义质量均待授权验收，未宣称准确率提升。没有真实付费调用、推送或部署；线上仍是上一轮版本。

兼容边界：旧客户端不传 capability_focus 时，后续按相同JD与原题作有限参考，不能保证已有标准快照；新前端在同一轮把首次结果复用。标准仍由模型解释，不是确定性招聘评分。用户更换JD/题目并重新诊断后使用新结果。没有增加后台存储或跨训练画像。
